## 沉浸式研究基地

首页使用明亮的原初生态研究所与左侧游戏菜单，独立培养台和五种母体按脚底锚点合成；底部玻璃栏可切换五条成长谱系。窄屏从左上角“菜单”进入功能。图鉴支持右侧详情与列表，实验室按“条件 → 候选 → 风险与投入”展示。存档导出位于人员记录。

## 从第一只小生物开始

五种母体采用沉静、带神性的原初生命形态，以玉质种核、莲芽、古木根灵、灵菌与玉甲虫区分谱系，保留少量小巧亲和感。首页一次展示一种母体，切换谱系同步切换主角。特化与杂交后长出更复杂的结构，最后进入异常与零序列阶段。变种档案可查看前后形态、能力及实验线索。

永久成长来自实验解锁新物种；出征中三个同星个体合成为更高星，属于本局养成，不改变永久谱系。未知形态仅展示剪影，发现后揭晓。

## 操作与循环

1. 在出征部署选择物种池：未满 12 种时携带所有已解锁模板，达到后选择 12 种；五个费用档均需覆盖。探索倾向影响试剂奖励类型，完整出征仍包含 20 回合。
2. 商店购买后进入备战席。点击个体，再点击己方下三行格子部署；可换位、撤回和出售。出售退还组成个体的实际购买费用。
3. 每回合有一次免费刷新，之后 2 BIO；可锁店。4 BIO 购买 4 容量经验。利息、连胜败及生物收入分别显示。
4. 主动开始自动战斗。战败不会永久失去购买个体；每个完成回合获得试剂。第 6、13、20 回合为 Boss。
5. 返回研究中枢保留出征。遗传实验室先公开试剂消耗、概率与失败风险，确认才消耗；模板永久保留。发现物种可加入下一局出战池。
6. 谱系网络支持拖动、缩放和节点查看，也有列表视图；Tab 与 Enter 可操作。空格暂停，Esc 取消或关闭弹窗。失焦后必须主动继续。

设置提供独立音乐、音效、静音及减少动态效果。数据只在本机浏览器中保存，不同浏览器不共享；可在人员记录导出档案。战斗刷新会回到本回合开战前，以相同种子重战。
