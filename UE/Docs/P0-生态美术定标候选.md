# P0 生态美术定标候选

本批是角色和研究所环境的美术候选，尚未完成 P0 人工美术验收，也不是 P1 主线样章或完整 1.0。

## 已接入内容

- Belica 模型继续使用同骨架的原生移动动画。上身、下身和腕部终端使用独立材质实例，象牙白装甲、苔绿软材质与黄铜点缀，不修改皮肤、头发或原始材质。
- 原创育生杖候选替换圆柱占位道具：握柄、陶瓷杆、黄铜环、发光种子与保护骨架。模型 6,776 三角面，四个材质槽；手指握持和左手姿态仍待进一步处理，不能称为已完成角色动画美术。
- Poly Haven 的 fern_02 和 boulder_01 模型，rock_01 和 forest_ground_04 贴图。使用 2K 文件，下载 MD5 与官方元数据逐项比对。当前场景有 100 个蕨类、44 个扫描岩石实例。
- 250 米宽、20,000 三角面的原创地形网格仅作为温室外景，不计入主世界可探索面积。它不参与导航或游戏碰撞。
- 新地图 P0_Conservatory_Ecology 按原有验证过的建图方式创建，保留导航测试障碍。玻璃墙改为透视材质。
- 通过 UE 编辑器实际地表射线与模型包围盒修正贴地，不使用 Blender 坐标推算作为最终依据。

## 可复现制作顺序

download_ecology_assets.ps1 → build_ecology_props.py（Blender）→ import_ecology_assets.py（UE）→ create_ecology_scene.py → ground_ecology_scene.py → fix_ecology_navigation.py → finish_ecology_materials.py → build_ecology.ps1 → test_ecology_package.ps1。

旋转使用命名参数；本机 UE Python 的位置参数顺序不同于 C++，已经在实际场景中验证。导航阶段显式构建、等待完成并检查完整绕障路径，失败时拒绝继续；不能仅以地图保存成功判断可用。

建图脚本拒绝覆盖已完成的同名地图；重新制作应使用新版本路径。上一版角色包和地图保留。验证结果见 ecology-verification.json，不以脚本存在代替运行证据。
