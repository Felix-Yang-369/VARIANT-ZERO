# 样章：声音与阅读设置

暂停菜单第七项为「声音 / 阅读设置」。支持鼠标、键盘和手柄菜单导航。

- 总音量、音乐音量、音效音量独立调整，每次减少 10%，到零后再次点击恢复 100%。
- 音乐设置同时作用于平静与警戒层；暂停菜单中调整也会立即应用。静音音乐不影响工具音效。
- 音效设置作用于后续播放的工具、护盾、修复等提示音；页面提供脉冲和修复试听。
- 对话正文和研究记录字号可选择 18、24、30；对话标题随正文增大。长记录继续支持滚动。HUD 和普通按钮字号不在本轮调整范围内。
- 恢复默认需要二次确认，可取消；不会改变键位、角色存档或任务进度。
- 设置保存在既有 `VariantZeroSettings.ini`，与角色存档独立。保存键位保留音画设置，保存音画设置也保留键位。旧配置缺少新字段时采用默认值；超范围音量被限制在 0–1，不支持的字号回到 18。
- 写盘失败会明确提示；设置仍在本次运行中生效，不声称已经持久保存。

## 验证

扩展现有 `VZMenuTest`：测试暂停中的音乐静音、独立音量、配置重读、键位保存互不覆盖、恢复默认的确认与取消、非法配置处理，以及实际 UMG 正文的字号。原菜单暂停、存档、键盘和手柄事件、恢复后实际按键仍继续回归。

构建：`Scripts/build_presentation.ps1`。打包验证：`Scripts/test_presentation_package.ps1`。验证记录：`Docs/presentation-verification.json` 和 `Docs/presentation-build-manifest.json`。

本轮没有生成语音、购买素材或消耗外部生成额度。主线中文配音、语音独立音量、音素口型、最终字幕系统仍未实现；阅读字号不等于主线配音已交付。当前继续完善 P1 样章，不代表进入 P2 或完成 1.0。
