# 伙伴管理原型

入口：Esc → 地图 / 研究记录 / 快速移动 → 伙伴管理 / 名字 / 出战顺序。

- 上一只 / 下一只浏览已经结识的伙伴，显示物种、等级和出战技能槽。
- 文本框输入名字，再点击“保存伙伴名字”。支持中文，最多 16 个 UTF-16 单元；空白名字、控制字符和换行会被拒绝。改名不会改变 GUID、物种、故事或共同经历。
- 向前 / 向后调整已出战伙伴顺序。技能槽随顺序变化，当前角色对象、生命、个体冷却和经历保留。不会重建伙伴或恢复生命。
- 选择伙伴后默认显示该个体已有的经历；保留初芽故事回看，原同物种记录按钮改为研究所整备。
- 每次有效修改均先提交自动存档，再改变内存状态。保存失败时保持原资料。
- 战斗、主角倒地或伙伴执行落点指令时不能编辑。
- 鼠标、键盘与手柄可浏览及排序。自定义名字需要键盘输入，尚未制作手柄虚拟键盘。

后续已增加研究所培养台附近入队 / 留守与休整，详见「研究所整备.md」。仍不提供放生、伙伴专长或完整培养界面，不能计为完整 1.0 成长系统。
