# 探索音乐与受击反馈

花庭探索使用已获用户认可的《根系之外》v2 混音。研究所保留《玻璃下的春天》派生配乐；穿过花庭入口后平滑切换，战斗时淡出探索混音并淡入警戒配乐，结束战斗后恢复。所有音频离线打包，受音乐音量与总音量控制。

原始 WAV 保留不动。派生循环为 125 秒、44.1 kHz、16-bit 立体声，尾部交叉淡化 3 秒，边界 10 毫秒消除突变。源文件及派生文件 SHA-256、峰值、边界检查见 `ArtSource/Audio/Exploration/manifest.json`。实际听感仍需用户试听确认。

当前使用完整混音，鸟鸣和无词人声随探索音乐整体降低；尚未做独立环境声轨。这不代表完成六组场景音乐。

真实扣血现在触发受击音效，覆盖主角、伙伴与异常守护者；无敌、无效伤害及已倒地对象不触发。80 毫秒间隔防止多个伙伴同时命中造成音量叠加。音效音量为零时不播放。
