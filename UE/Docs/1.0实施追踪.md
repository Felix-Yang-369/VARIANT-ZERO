## 批准的产品边界

Windows、单机、离线、第三人称、写实幻想生态 RPG。目标主线 4–6 小时，全收集 7–10 小时，需试玩验证。一个约 1×1 公里连通 World Partition 世界，可探索 0.3–0.5 平方公里。研究所常驻、三片生态区、最终核心室内按需加载。

核心：探索异常 → 观察/战斗/解谜 → 样本与记忆 → 培育 → 伙伴能力 → 修复世界打开路径。

翠绿网络传递适应记忆，生态署将它锁定在“安全的春天”；枯潮源于失去适应能力。主角恢复变化，也照顾依赖旧秩序的生命。一个完整结局，局部选择改变植被、水路、对话与陈设，通关后可回访。

固定女性生态师可修改称呼；管理员、流浪育种师、调查员、前任园丁为四位重要 NPC。主角和 NPC 共用适配人形骨架。场景内对话、基础表情与音素口型。无多人、捏脸、切换人形主角、自由建造、坐骑、飞行、自由攀爬、深水游泳、饥饿系统。

## 伙伴与培育契约

携带 3 只，仅队伍实例进入场景 AI。每物种一个主动技、一个被动、一个生态标签。个体保存名字、外观差异和经历；初芽、守午、拾声是个体，不是额外物种。倒地不永久死亡，主角复活不丢关键物品。故事/标准难度同奖励。

12 种固定身份：V-001 原豆母体、V-002 原花母体、V-003 原根母体、V-004 原孢体、V-005 原节肢体、V-006 双荚体、V-011 晨露花、V-016 荆棘根、V-020 毒雾菌、V-039 孢子豆、V-041 菌翼蛾、V-045 零序列载体。

等级上限 20、固定成长及少量专长；主线能力保证获得。杂交不消耗父代，首次主线实验确定结果，额外实验公开概率并保留失败进度。固定培养台与装饰插槽。零序列通过主线后期研究获得。主世界与演练只共享物种身份，不共享数值。
