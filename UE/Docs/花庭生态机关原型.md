# 无访花庭：生态机关原型

本轮在独立地图 `P0_Conservatory_Garden` 中延伸温室，验证解谜、伙伴生态能力、战斗与持久状态之间的连接。它仍是关卡原型，不是通过验收的 30–45 分钟 P1 样章。

## 试玩路径

1. 用项目根目录「开始游戏.bat」启动故事模式，完成温室采样、培育、训练、修复、菌翼蛾研究与传粉。存档格式仍兼容；各旧试玩包的存档保留在各自目录，本轮不自动覆盖或合并。
2. 带上菌翼蛾，在温室北侧「无访花庭」目标旁按交互键，进入新检查点。
3. 接近三座导光装置，扫描读取朝向线索，交互顺时针转动。每次调整自动保存。装置按西、东、北的位置排序，要求分别朝东、西、南。
4. 中间隔墙的右侧保留绕行通道。光路完成后，带健康的菌翼蛾靠近中央花冠并交互。
5. 守护节点防护打开八秒。标记目标后使用脉冲与伙伴技能，同时躲开地面预警。防护关闭后可以再次让菌翼蛾协助开启。
6. 平息节点后自动提交修复：四份研究样本、共同经历、可见供水与中间捷径。返回入口档案台报告，仍可回访温室。

## 实现与边界

- 机关朝向、花庭阶段、检查点、修复、奖励收据使用现有版本化存档；未改存档格式，不覆盖旧版本打包目录。
- 只有当前花庭组件检测到节点清除时才请求修复事务。纯规则层校验任务阶段、光路和队伍，并保证奖励去重；写盘失败不更新内存进度。
- 死亡重置战斗及破防计时，保留已存机关朝向。读档恢复捷径和供水表现。
- 地图扩建约 26×57 米，保留动态地面导航。供水采用发光渠道占位表现，没有制作流体模拟。
- 守护节点复用已有练习节点的几何、生命值和攻击，尚不计入正式三场守护者数量。当前没有新增正式 NPC、中文配音、World Partition 或新生态区域成品。
- 当前验证通过不能证明战斗节奏、写实美术、时长或新玩家体验达标。

## 验证入口

- `Scripts/test_native.ps1`：六组原生规则测试，包含花庭门槛、非法事件、机关续档与奖励去重。
- `Scripts/test_garden_package.ps1`：打包版花庭流程，以及开场、角色、基础、战斗、指挥、菜单回归。
- `Docs/garden-verification.json`：实际打包结果；`Docs/garden-build-manifest.json`：最终二进制摘要。
- `Scripts/create_garden.py` 与 `finish_garden_scene.py` 是本轮地图创作脚本；已有地图不能反复覆盖生成。

下一步仍需完善 P1 的场景、守护者动作与阶段、任务内容、中文主线音频，再进行新玩家实测；不能跳过样章门槛批量生产后续区域。
