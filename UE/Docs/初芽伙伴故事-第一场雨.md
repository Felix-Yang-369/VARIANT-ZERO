# 初芽伙伴故事《第一场雨》

这是 P1 样章中的可选伙伴故事短篇原型，不是已完成的 30–45 分钟样章。保留全部温室、花庭、两阶段守护者、回访、阅读设置与存档功能。

## 体验路径

1. 完成花庭修复，并在入口档案台报告。
2. 带健康的初芽靠近同一档案台，再次交互接受「第一场雨」。
3. 带它前往「低处的根」「旧水位线」「高处的新叶」。靠近目标并扫描；顺序不限，观察自动保存，可反复回看，不能重复计数。
4. 三处观察完成后，返回档案台北侧的两处修复标记。西侧交互选择「扩建浅水带」，东侧选择「保留干燥岛」。提交前的记录会解释两者差异。
5. 两者都完成故事，获得一份研究样本。浅水带把植物放在水边；干燥岛把植物放在透气土床。地面陈设、结局文本与初芽的经历随选择保存。
6. 暂停菜单「研究记录 / 快速移动」中的初芽共同经历，可回看观察与选择结果。

## 状态与边界

- `story.chuya` 0/1/2/3 分别代表未接受、观察中、待选择、完成。三个观察点用稳定 ID 去重；选择互斥，奖励收据为 `story.chuya.reward.v1`。
- 新存档给最初伙伴添加来源记忆。旧原型存档按既有获得顺序识别首个 V-001，首次接取后固定其个体 ID；后续改名或数组重排不会更换主角。新芽不会代替初芽获得故事记忆。
- 初芽不在队伍、倒地、距离过远或仍有战斗时，不能推进观察与修复；不消耗材料，也不删除伙伴。
- 所有推进通过已有持久提交入口。写盘失败保持原进度；读取未选择的旧手动槽会回到该槽的真实历史，不跨槽合并奖励。
- 陈设复用现有引擎基础网格和已登记 CC0 蕨类，不改变导航碰撞。还不是正式环境美术、流体模拟或新增生态地区。
- 本轮没有中文语音录音或电影过场；不将此短篇自动计为正式伙伴故事的最终验收完成。
