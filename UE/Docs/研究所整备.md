# 研究所整备与伙伴入队

在研究所培养台附近打开暂停菜单 → 研究记录 → 伙伴管理，选择伙伴后使用「留守并休整队伍」或「入队并休整队伍」。地图中的「培养台 · 伙伴整备」可设置导航。整备范围为培养台周围 4 米。

- 队伍保持 1–3 只；满员时先让一只留守，再选另一只入队。
- 留守伙伴保留个体 ID、姓名、等级、外观种子和全部经历，不生成场景 AI；重新入队不创建新个体。
- 入队追加到最后技能槽，可通过已有排序操作调整。
- 整备作为研究所休息行为，恢复主角与当前队伍生命、工具及技能冷却；普通排序仍保留原生命和冷却。
- 野外、战斗、主角倒地、对话、技能瞄准和伙伴执行指令时不允许整备。
- 先提交自动存档，再改变实际队伍；保存失败不会移除伙伴或恢复生命。

初芽故事要求原来的初芽，花庭机关要求菌翼蛾。留守后可以通过研究所快速移动点回来重新入队；不消耗材料，也不删除任务进度。地图培养台标记不会因主线阶段改变而消失。

现有两个原豆个体与菌翼蛾可实际操作。12 个物种的正式模型与技能、等级成长、专长、照料动画仍未完成。留守伙伴暂以资料表示，尚未制作研究所伙伴展示区。

## 验证范围

扩展既有伙伴与地图原生测试：未知个体、重复加入、容量上限、最后一只不能留守、菌翼蛾回队、经历保存、留守资料读档和培养台常驻标记。

扩展实际菜单回归：野外拒绝、执行指令拒绝、保存失败保留实际角色与生命、角色退出场景 AI、原个体重新生成、自动存档读取及战斗中拒绝。

本项属于样章伙伴系统开发，不代表完整 1.0 或人工试玩验收完成。
