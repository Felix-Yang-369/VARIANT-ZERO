# P0 资产接入版

这一批完成的是 P0 的资产管线和温室体验推进，不是 P1 的完整主线样章。

## 初芽

沿用原有 `原初生态研究所_V-001_原豆母体_v2.blend` 的独立角色集合，原文件未改动。

- 约 14.3 万三角面的源集合转换为 2.2 万三角面的候选网格；Blender 顶点 11,993，所有顶点有归一化骨骼权重。
- 11 根骨骼，包含身体、双足、冠芽与两侧叶片链；待机约 2 秒、移动约 1 秒循环。
- 一个材质槽，2048×2048 基色、法线、粗糙度、发光贴图。原程序材质已烘焙，运行时不依赖 Blender。
- UE 三级 LOD；导入顶点分别为 24,945 / 7,666 / 3,909（UV/法线拆分会使引擎顶点数高于 Blender）。
- 保存并重新打开 Blender，验证权重、贴图打包、骨骼、动画实际顶点变化与变形边界；随后重新打开 UE 检查网格与动画骨架引用。
- 使用原有跟随逻辑，依据速度切换待机和移动动画；角色胶囊负责世界碰撞，骨骼网格不参与阻挡玩家。

资产身份：**绑定后的引擎候选版**。它基于已有造型自动减面，局部叶脉/烘焙接缝和动作表现仍需人工修整；不能据此宣称正式角色美术全部完成。

文件：`ArtSource/Chuya/v1/Chuya_bound_v1.blend`、三个 FBX、四张贴图与验证报告。UE 路径 `/Game/VariantZero/Characters/Chuya`。

## 温室

新地图 `/Game/VariantZero/Maps/P0_Conservatory` 包含 280 个静态网格 Actor：拱架、纵向支撑、培养岛、矿物地面、发光步道、植物和第一株花床。使用引擎基础几何与原创材质，日光和天空大气已加入。

动态导航覆盖温室；中部设置真实阻挡物，自动检查导航路径是否绕行。修复花床后的花瓣材质由存档状态驱动，读取旧状态也会更新表现。这个场景仍是美术开发候选；墙板不是正式透光玻璃，植被也不是最终植物资产。

## 验证范围

`p0-next-runtime.log` 记录打包版的骨架/动画/LOD、材质资源、导航绕行和原有存档/奖励/复活冒烟测试。`p0-next-packaging.log` 记录 Windows 打包。`ArtSource/Chuya/v1/reopen-verification.json` 记录 Blender 重开检验。

自动导航测试证明路径能绕开障碍，不等于已人工验证伙伴所有复杂地形行为。自动动画播放检查与 Blender 变形检查不替代逐动作视觉评审。当前没有测得正式 60 FPS/1% low 目标，也没有完成两小时连续运行。
