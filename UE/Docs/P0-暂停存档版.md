# P0 暂停与存档界面

本批完善温室试玩的操作入口，仍属 P0，不计为已完成的主线样章。

## 如何使用

双击工程根目录的 `打开P0测试版.bat`。按 Esc 或手柄左侧菜单键打开终端，暂停世界中的移动、攻击与冷却。鼠标点击、键盘方向键与 Enter、手柄方向键/左摇杆与 A 均可操作；Esc 或 B 返回。

- 继续探索：关闭菜单后恢复世界，清除开菜单前按住的攻击与冲刺，避免误触。
- 手动槽：循环选择 1–3 号槽，显示文件时间（UTC）或空槽提示。
- 保存：已有文件时再次确认；保留原有版本化存档与备份逻辑。
- 读取：可读取选中手动槽或自动槽；再次确认后返回检查点，重置当前遭遇，保留读取到的任务与伙伴。
- 难度：故事/标准切换后自动保存，两档奖励一致。
- 总音量：每次减少 10%，降至零后循环回 100%；写入本机设置文件，独立于任务存档。
- 操作说明：菜单中显示键鼠与手柄战斗提示。
- 退出：再次确认后退出；不额外执行保存。

所有确认都在游戏界面中进行。按返回取消确认；读取失败保持菜单打开并显示错误。存档损坏、未来版本保护和备份恢复继续沿用已有实现。修复了读取失败的手动槽会错误解除已有写入保护的问题。

## 实现与验证入口

`VZPlayerController.*` 使用 UE 原生 Slate 菜单，直接调用现有状态事务；没有另建一套存档格式。它是当前可用的原生界面，尚未迁移为最终 UMG 美术组件。

`-VZMenuTest` 使用隔离存档，并检查暂停前后攻击计时、位置、按住攻击释放、菜单键盘与手柄键事件、保存/读取确认、取消覆盖、个体身份、失败读取保护、难度、音量设置和恢复推进。测试截图为实际打包界面。该测试覆盖软件输入路径，不替代实体手柄人工验收；当前战斗缺少正式声音素材，总音量尚无完整内容听感验收。

主世界美术仍是候选版，主角仍为 Quinn。按键重绑定、各音频类别独立音量、字幕设置、完整最终 UMG 界面、主线与配音仍未完成。

构建与验收结果见 `menu-packaging.log`、`menu-runtime.log`、`menu-smoke.log`、`menu-combat.log`、`TestResults/Native/index.json` 及 `menu-verification.json`。
