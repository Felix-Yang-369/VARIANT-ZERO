# P0 基础整合版

本批是完整 1.0 开发中的基础工作，不是 1.0 完成声明。

## 键位设置

Esc → 按键设置 / 操作说明。用“上一个/下一个动作”选中动作，点击键鼠或手柄一行后按新键。提供重复占用提示、恢复单项与全部默认。Esc 与手柄左菜单键始终保留；摇杆轴保持默认，数字按钮可以重绑定。手动存档/开发快捷键仍保留。

设置先写入本机文件，成功后更新当前玩家的输入映射，不修改全局项目默认键位。未知版本拒绝加载或覆盖；非法或冲突布局不会部分应用。音量修改保留已保存的键位设置。HUD 操作提示使用当前键位。

## 声音与环境

从原有《玻璃下的春天》合集取《原初之息》《共生前线》制作技术循环版，分别用于温室平静和警戒，两层随节点战斗状态渐变。原曲由项目 `scripts/audio/produce.py` 原创合成，无外部采样；没有导入含 FL Studio 人声采样的《根系之外》，也没有使用 Suno 主题曲作发行录音。

基础脉冲、护盾、照料提示声为本次原创合成，离线运行。它们仍需后续声音设计与实际听感评审；当前不具备完整音频类别音量设置或主线配音。

`P0_Conservatory_Foundation2` 是按原温室配方重新生成并重建导航的场景，原地图保留，补上外部地面、远处地形轮廓与高度雾，避免视野落到空场景。山体仍为基础几何候选，不计为正式生态区域或写实环境验收。

## 验证

4 个原生测试套件覆盖存档、物种、伤害和键位配置。打包菜单检查增加了“捕获新按键 → 保存 → 应用到玩家 → 用新按键触发真实脉冲”的路径，并检查离线声音引用和警戒混合状态。其余战斗、伙伴指挥、跟随和存档继续回归。结果以 `foundation-verification.json` 为准。

未做实体手柄人工验收、最终美术/听感认可、主线通关或发布性能验收。完整剩余工作见 `1.0交付门槛.md`。
