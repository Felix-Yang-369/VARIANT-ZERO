# P0 协作战斗版

本批在温室中加入一个可反复练习的失衡节点，让生态师与初芽形成基础战斗流程。它是工具验证场景，不是正式守护者，也不是 20 回合生态演练台。

## 试玩流程

1. 进入温室后按 T 激活失衡节点。
2. 按 Q 标记，再按住鼠标左键发射脉冲。未标记时需将镜头对准目标；射程 12 米，墙体会遮挡攻击。
3. 初芽靠近且视线畅通时自动攻击，按 1 指挥它释放更强的主动技能。
4. 节点攻击前会在地面显示橙色预警圈；走出范围、跳跃、Ctrl 闪避或右键护盾可以避伤或减伤。
5. 节点平息后，倒地伙伴自动恢复。返回花床按 E 照料，也可按 T 重开练习。

| 能力 | 当前规则 |
|---|---|
| 育生杖脉冲 | 12 伤害，0.55 秒冷却，12 米射程 |
| 短时护盾 | 持续 3 秒，减伤 80%，8 秒冷却 |
| 闪避 | 位移并提供 0.35 秒免伤；原 1.2 秒冷却保留 |
| 初芽基础攻击 | 5 伤害，1.3 秒间隔，8.5 米射程 |
| 初芽主动技能 | 32 伤害，6 秒冷却，11 米射程 |
| 节点攻击 | 1.1 秒预警；故事 18 / 标准 30 伤害，半径 1.65 米 |

主角倒下后回到检查点，恢复生命并重置本场。伙伴不会永久死亡或丢失个体身份。F1 切换故事/标准难度并保存设置，两档奖励规则相同。

## 输入与界面

新增中文目标提示、主角与初芽生命值、技能冷却、目标血条和难度显示。育生杖使用装配的临时杆体，技能效果为可见脉冲与预警，尚未制作正式攻击动作、Niagara 特效或配套声音。

新增手柄映射：RT 脉冲、LT 护盾、RB 初芽技能、菜单键激活节点。此前的移动、跳跃、闪避、交互、扫描映射继续保留。完整手柄菜单和按键重绑定仍未完成。

## 存档边界

这场工具练习不发放材料，不能靠反复重置刷取主世界成长资源。原花床的一次性奖励仍走原存档事务。

本场生命、冷却、节点伤害为临时状态；读取手动槽会回检查点并重置当前遭遇，不恢复半场战斗。任务、材料、伙伴个体和生态修复状态继续保留。不同打包目录不自动迁移玩家存档。

开发测试与预览参数 `-VZCombatTest`、`-VZPreview` 均使用独立随机测试存档目录，不读写玩家存档。`-VZPreview` 只在实际场景中设置展示镜头并触发已有技能，然后截图；没有用概念图替代运行画面。

## 验收与未完成内容

运行证据写入 `combat-packaging.log`、`combat-runtime.log`、`combat-smoke.log`、`TestResults/Native/index.json` 和 `Docs/combat-verification.json`。核对结果以最终报告为准。

这不是 30–45 分钟主线样章。写实主角、正式敌人、最终美术、技能音效、培育、主线中文配音、输入重绑定及完整手柄 UI 仍需继续制作。未做 60 FPS/1% low 或两小时稳定性验收。
