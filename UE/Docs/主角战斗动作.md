# 主角战斗动作原型

在研究所整备版本基础上增加三种实际动作反馈：

- 脉冲成功施放：上半身短促施放动作，手中的育生杖随手部骨骼移动。
- 护盾成功开启：上半身施法动作；下半身继续移动或跳跃，不额外锁定角色控制。
- 实际受到伤害：本地空间叠加受击动作；无敌和无效伤害不触发。

护盾的调试线框球替换为原创玉绿色半透明护罩，边缘比中心明显，能看清角色与动作。不参与碰撞、寻路或投影，持续时间仍为三秒，检查点恢复时立即隐藏。

受击优先于护盾，护盾优先于脉冲。同一动作播放中不会因连续事件每帧重启。动作淡入、淡出，结束后恢复正常移动姿态；死亡恢复和读取检查点会清理动作状态。表现不更改伤害、护盾持续时间、技能冷却或奖励。

## 资产

复用已下载的 Paragon Lt. Belica 包，不新增付费或生成额度。使用 `Primary_Fire_Fast`、`Cast`、`HitReact_Front`；来源时长、骨架和叠加类型记录在 `hero-action-source.json`。

脉冲和护盾按 `spine_01` 及其子骨骼混合，保留骨盆与腿部移动。受击源动画是 additive，使用正确的叠加求值，避免将差值姿态直接作为全身姿态。

这些是基于现成角色动作的适配，尚不是专为生态师制作的最终动作。专用闪避、伙伴攻击动作、面部表情、口型、过场及最终视觉特效仍未完成。既有素材发行许可仍应统一复核。
