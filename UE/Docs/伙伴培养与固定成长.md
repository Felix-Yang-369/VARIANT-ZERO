# 伙伴培养与固定成长

在研究所培养台附近，按 Esc → 地图 / 研究记录 / 快速移动 → 伙伴管理，选择伙伴，再选择「培养」。先查看数值与费用，再点击同一按钮确认；其他菜单操作取消确认。

培养点由主线进展保证获得，不消耗传粉研究等关键任务材料，也不依赖小游戏：温室花床修复 2 点、花庭供水 3 点、花庭报告 3 点。本样章总计 8 点；重复读档和回访不会重发。已完成对应任务的旧存档可直接使用尚未消费的培养点。

从 L 级升至 L+1 级消耗 L 点；等级上限 20。本样章的培养点有限，不能据此达到 20 级，完整世界成长供给与专长尚未实现。

| 数值 | 1 级 | 每级增长 |
|---|---:|---:|
| 生命上限 | 100 | 5 |
| 普攻伤害 | 5 | 0.5 |
| 初芽主动技能伤害 | 32 | 2 |
| 菌翼蛾治疗量 | 20 | 1 |

主动技能快捷键与指定落点共用成长数值；物种身份、个体名字、共同经历和父代伙伴不变。培养成功后队伍休整，失败不扣培养点、不升级、不重建角色。培养仅允许在培养台附近、非战斗、未倒地且无伙伴执行落点指令时进行。

存档沿用已有伙伴等级字段，另以稳定状态 ID `growth.spent` 保存累计消费，无存档版本变更。奖励额度从已保存主线进度计算，按当前等级校验提交，拒绝重复提交过期的升级操作。

原生伙伴规则测试覆盖额度、费用、重复提交、材料隔离、等级上限和固定数值；打包菜单测试覆盖确认、存盘失败回滚、真实生命上限、读档、远程及战斗拦截。仍需人工评估升级节奏与战斗平衡；该实现不代表完整 1.0 成长系统完成。
