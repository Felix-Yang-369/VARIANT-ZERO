# 研究记录与快速移动

暂停菜单新增「研究记录 / 快速移动」。研究所默认可回访；第一次接受花庭委托后解锁花庭移动点，不要求先击败守护节点。尚未解锁的地点会说明原因。

## 玩家操作

- Esc 打开暂停菜单，选择最后一项「研究记录 / 快速移动」。键鼠与手柄均可选择。
- 选择研究所或花庭返回对应检查点。战斗中、主角倒地或花庭修复尚未结算时不可传送。
- 可回看温室记录、花庭任务、初芽与菌翼蛾的共同经历、研究材料和花庭礼包领取情况。
- 长记录用滚轮、PageUp/Down 或右摇杆滚动；Esc / B 返回上一层，再按一次继续游戏。

## 持久化与限制

传送前检查地点解锁状态、场景导航、战斗与主角状态，再将目的地检查点写入自动存档。写盘失败时留在原地，内存进度不变。提交成功后恢复队伍并重置镜头。伙伴保留同一个体 ID、姓名和经历；不添加材料、奖励收据或任务阶段。

研究记录从已保存的任务与伙伴状态生成，未到达花庭时不提前展示修复结论。原存档格式不变。本功能目前只覆盖已制作的研究所与花庭，不开放尚未制作的地区。

当前界面沿用原生暂停菜单，是功能实现，不代表最终 UMG 地图与美术界面已经完成。五种角色中文配音、完整 P1 时长、后续区域和原生演练仍待开发。

## 验证

- 原生测试 `VariantZero.World.TravelAndRecords`：未解锁地点、非法 ID、检查点落盘、反复回访的资源与身份保护、记录按进度显示。
- 打包测试 `VZTravelTest`：从暂停菜单打开记录、写入失败不移动、战斗/倒地阻止移动、导航落点、伙伴重建、自动读档与双向返回。
- `Scripts/test_travel_package.ps1` 同时回归花庭、开场、角色、基础、战斗、指挥、菜单。以 `Docs/travel-verification.json` 的实际结果为准。
