# 样章地图与导航

入口：Esc → 地图 / 研究记录 / 快速移动 → 打开地图 / 标记目标。

这是根据现有温室与花庭布局绘制的 UMG 示意地图，不代表完整 1.0 主世界已经制作完成。以 +Y 为北、统一厘米比例投影；显示玩家位置和镜头朝向、当前任务目标、已解锁移动点。花庭尚未到达时隐藏内部布局，不提前显示剧情结果。

地图目标直接读取温室、花庭和初芽故事任务规则。已采集的样本等不再列为待完成目标。绿色为快速移动点，金色为任务目标，蓝色为玩家；选中地点会显示直线距离。

## 操作

- 鼠标点击地图上的编号地点，再点击右侧操作。
- 键盘左右 / 手柄十字键左右切换地点，上下切换操作，Enter / A 确认。
- 设置导航标记后返回探索，画面显示目标方向与距离。此标记是本次探索的临时书签，不写入存档；读档和成功快速移动后清除。
- Esc / B 返回研究记录，仍保持暂停；继续探索才恢复主世界。
- 快速移动只作用于已解锁的研究所或花庭入口。任务目标不能直接传送；战斗、倒地、修复尚在结算或自动保存失败时保留原位置，并显示原因。

地图不是路径规划器。直线距离可能穿过墙体，导航标记不保证眼前路线可通行；请利用实际道路和修复后捷径。

## 验证范围

新增 ChapterMap 原生测试：新档目标、未探索地点隐藏、任务推进同步、移动点与存档规则一致、坐标方向和比例、非法状态拒绝。

扩展打包 Travel 测试：UMG 界面、暂停、手柄选中和标记、不能传送到任务目标、清除标记、返回层级、解锁后重新打开、存档失败留在地图、移动后清除旧标记。保留其余战斗、伙伴、故事和音频回归。

这仍是 P1 样章中的导航功能；不等于 P0/P1 美术、叙事、主线中文配音和新玩家试玩已经验收。实体手柄和 30–45 分钟连续试玩仍需验证。
