# VARIANT ZERO｜独立乐器分轨

2026-09-08 导出。五首 BGM 共 33 条干声乐器轨、5 条共享混响轨；另外每首附两份参考混音。所有文件为 44.1 kHz / 24-bit / 立体声 WAV。

## 导入 GarageBand、Logic Pro 或其他编辑器

1. 新建空音乐工程，节拍设为 4/4；按下表设置歌曲速度。支持采样率设置的编辑器使用 44.1 kHz。
2. 打开对应歌曲文件夹，把编号开头的 WAV 分别放在独立音轨上，全部从第 1 小节起点（00:00）开始。不要首尾串联。
3. 暂时保持轨道音量 0 dB、声像居中，关闭自动归一化、自动节奏匹配和时间拉伸。文件已经包含原始立体声声像。
4. `90-reverb-return.wav` 是共享空间混响，可单独调整音量。想自己加混响时，将此轨静音，再给乐器添加新的效果。
5. `reference-premaster.wav` 是未经过母带饱和处理的参考混音；与编号轨同时播放会叠加变响。`reference-mastered.wav` 是原版母带处理参考。两条参考平时静音，只用于独奏对照。

可以逐轨调音量、静音、剪辑、加 EQ 和效果。WAV 是已经渲染的声音，不是 MIDI，不能直接逐个拖动音符；修改旋律音符或更换合成音色需要编辑制作脚本重新导出。

共享混响轨包含所有乐器的原始反射，静音某条干声时仍可能听到它的混响。需要彻底移除某乐器时，同时关闭共享混响，给保留乐器重新加效果。

## 再次生成与验证

在项目目录运行 `python3 scripts/audio/produce.py --stems-only`，只重建分轨，不替换游戏里的 BGM 和音效。每首的 `session.json` 记录速度、长度、轨道名与导出增益。

验证命令：`python3 scripts/audio/verify_stems.py`。五首均通过长度、格式、无削波和叠加重建检查。分轨加混响与 premaster 的最大采样差小于 0.000002；mastered 参考与现有 16-bit 母带在原始量化精度内一致。母带包含非线性饱和，不能期望单独乐器相加直接还原该母带处理。
