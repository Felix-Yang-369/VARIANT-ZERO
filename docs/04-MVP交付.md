# MVP 交付与验证

日期：2026-09-05

## 当前交付

游戏暂名“芽芽保卫战”。Phaser 3.90.0 + TypeScript + Vite，原创 SVG 角色与程序绘制场景，不依赖远程资源、账号或服务端。

已实现三关、六种基础植物、四种进化形态、三个固定杂交结果、四种敌人，以及完整的种植、资源、冷却、战斗、胜负、重开与本地解锁循环。

第一关开放阳光花、豆射手、护盾果；第二关开放冰芽、速射苗和分支进化；第三关开放爆爆花及杂交。进化和杂交互斥，不允许递归组合。

## 与初始设计的区别

- 初始阳光按关卡调整为 175 / 225 / 275，降低原型开局压力。
- 将菜单、关卡选择与战斗整合在同一页面，减少页面切换。
- 只有合成操作音效和音效开关，没有背景音乐与独立音乐开关。
- 使用程序化摇摆、命中闪烁和扩散圈，没有逐帧角色动画。
- 本地存档保存最高解锁关卡和音效开关，未保存每关详细通关统计或进行中的战斗。
- 无在线部署；通过本地开发服务器试玩。

## 自动化验证

`npm test`：11 项测试通过，包含无效种植不扣费、冷却、阳光单次收集、暂停冻结、进化/融合血量继承、失效材料、禁止递归、高速子弹命中、一次性防线车、胜负状态与新局清理。

三关均通过使用真实资源、生产和冷却的自动通关策略。模拟自动收集阳光，不能替代真人操作难度测试；目前基础射手阵容可通关，进化与杂交的策略价值仍需后续调优。

`npm run build`：类型检查和生产构建通过。引擎与应用约 1.23 MB JS，gzip 约 332 KB；构建会提示单个 bundle 较大，当前可正常运行。

## 浏览器验证

使用 agent-browser 的 Chromium 会话检查。已验证页面与棋盘渲染、基础植物种植和扣款、暂停计时冻结、分支进化、杂交预览与成功生成光能射手、保存后关卡解锁恢复。用于查看后续关卡的测试存档在检查后清除。最终浏览器错误列表为空。验证时发现内嵌 SVG 需以 base64 交给 Phaser 加载器，已修复。

后续不应把此结果描述为已完成 Safari、真机移动端或 100 敌人 / 200 子弹压力验收；这些尚未进行。

## 运行

见根目录 README。执行 `npm ci` 后运行 `npm run dev`，打开终端给出的地址。

建议先试玩第一关，观察资源节奏与路线压力，然后再调整第二关进化和第三关杂交的成本。
