# 美术与成长阶段

用户方向：基础母体简单可爱，逐步变帅、变复杂，形成一步一步成长的养成感。

| 阶段 | 视觉原则 | 当前实现 |
|---|---|---|
| 幼生母体 | 圆团、大眼睛、短肢体、少量叶片；五种保持易辨认 | 五母体透明图集 `vz-founders.png` |
| 专长生长 | 只长出一两个功能器官，保留幼生亲和感 | 双荚、冰豆、爆裂豆、晨露花、共鸣花、荆棘根、地缚根、毒雾菌、爆孢菌、蜂群、猎杀螳，11 格少年图集 |
| 特化／融合成体 | 分枝、装甲、多器官、明确战斗职能 | 高阶变种与 12 种融合后代 |
| 异常觉醒 | 能量纹路与异常结构成为焦点 | 三异常体 |
| 零序列 | 环形遗传结构、洋红异常色 | 零序列载体 |

图鉴标记阶段，并显示父代 → 当前 → 后续形态。未发现的节点隐藏名称和完整彩色外观。不同分支不强制经过全部五阶段；稀有度、分类与成长阶段分别表达。本局星级不会改变永久物种谱系。

新增角色由本地可调用的图像生成工具原创制作，真实透明 Alpha PNG；游戏按图集坐标复用纹理。旧九种杂交后代沿用工程素材。新素材清单：`vz-founders.png`、`vz-juveniles.png`、`vz-sheet-1.png`、`vz-sheet-2.png`、`vz-sheet-3.png`。原图保存在 `public/art/`。

最终少年图集生成提示词：

> 为原创游戏制作一张真正带透明 Alpha 通道的角色素材图集。4列3行，每格一个角色，最后一格留空。背景必须透明，直接交付可用于游戏的抠好图角色 PNG。角色是简单可爱的少年生物，柔软的3D玩具般质感、圆润轮廓、少量器官，尚未长出复杂盔甲。第一行：双小炮口青豆；冰蓝小炮口青豆；橙色爆裂果豆；捧露珠的白色小花。第二行：紫色铃铛花；长出几根刺的小橡果；长出两只根须手的树根宝宝；紫色毒素小蘑菇。第三行：橙色圆鼓鼓爆孢菌；两只小蜜蜂组合；少年绿色螳螂；空格。每个生物完整身体居中，身体不越过自己的格子，格子之间留出透明间隔。固定四列三行均匀布局，温暖左上光照，眼睛可爱。没有文字。不要制作展示海报，制作透明背景的游戏素材。

品牌图标使用本地 SVG 生物环 0、遗传链与洋红异常分叉，导出 32px PNG 和 180px Apple Touch 图标。所有游戏属性、名称、概率和按钮仍为真实界面文本。
