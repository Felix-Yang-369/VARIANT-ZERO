# 界面视觉优化记录

日期：2026-09-06。沿用现有生物素材，调整界面结构与独立视觉样式，不改变战斗、经济和存档规则。

- 公共导航使用分组按钮与细光条标记当前位置，品牌按钮去掉整块选中色。
- 页面标题统一左侧引导线、编号和层级，深绿背景增加局部亮度变化。
- 主页培养舱加入玻璃双层边缘、静态状态点、舱体编号与底座；指标使用分隔线。
- 物种卡加入标本底座、角标、编号和谱系配色。母体、成长阶段、能力及 BIO 费用层级统一；未知标本保留剪影。
- 实验室增加材料培养区，风险、消耗与结果使用一致面板。谱系节点、成长对照、人员统计、设置弹窗统一边缘与阴影。
- 部署页增加温室氛围背景、棋盘外框与商店材质。紧凑商店使用独立字号和图片尺寸。
- 减少动态效果时禁用按钮与卡片过渡；无模糊支持时仍使用不透明面板。

实现：`src/variant/visual.css` 为独立视觉层；`main.ts` 增加标本展示容器与页面标识。

验证：Chrome 153.0.8010.12，8 项既有浏览器测试全部通过；1280×720、1366×768、1440×900 棋盘与商店布局通过，390px 页面无横向溢出。人工查看主页、1280 部署、桌面与窄屏组池截图，确认主要文本与入口可见。生产构建通过，保留 Phaser 分包体积提示。Safari 本轮未执行。
