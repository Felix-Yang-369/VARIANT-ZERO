# 沉浸式生态实验室 · 界面升级

2026-09-06，延续 v0.4 游戏内容。本轮重做界面与环境美术，战斗规则、经济、45 物种定义和 v4 存档结构均沿用。

## 页面与操作

首页使用全屏温室、左侧固定菜单、三界母体和底部研究信息。成长预览支持五条谱系手动切换；未知物种显示编号与剪影。真实发现数与活动出征回合、完整度位于顶部。已保存出征的入口显示“继续出征”。

桌面子页面采用 208px 侧栏，首页为 260px。390px 窄屏使用菜单抽屉：Tab / Shift+Tab 在菜单内部移动，Esc 关闭并恢复焦点；设置弹窗沿用键盘焦点管理。

图鉴采用主区域加右侧详情，右侧显示标本、成长和直接遗传关系；手机显示在主内容下方。谱系可拖动、滚动和缩放，也可切到列表视图。

实验室依次为条件选择、培养台候选、风险与消耗。确认前公开概率和投入；结果区分别呈现新发现、重复与失败，以及实际投入和返还。保存先完成，动画仅负责呈现。

人员记录集中展示成绩、区域调查、旧版纪念与本地保存说明，存档导出入口从首页移至人员记录。旧版纪念不再直接显示 JSON。

战斗采用独立全屏框架：左侧羁绊与操作教学、中间棋盘与八格备战席、右侧个体与开战操作、底部五格商店。顶部返回中枢会暂停当前战斗，重新进入后需主动继续；放弃仍需确认。空格暂停、Esc 取消、数字 1–5 购买保持可用。

## 展示层结构

- `src/variant/ui/shell.ts`：共享框架、导航图标、页标题与纪念展示。
- `ui/home.ts`：首页场景、真实进度与五系成长预览。
- `ui/specimen.ts`：标准与紧凑物种卡，剪影、费用不足和选中状态。
- `ui/views.ts`：组池、档案、实验室和人员页面模板。
- `ui/modal.ts`：统一弹窗容器；暂停及焦点生命周期仍由主入口管理。
- `style.css` 与 `ui/components.css`：整理后的布局、材质与组件样式。旧 `visual.css` 不再加载。
- `renderer.ts`：三区域环境纹理、透明部署格、区域切换和原有角色表现。棋盘仍为 800×600 逻辑画布，48 个 HTML 格子等比覆盖。

本轮只增加展示类型、组件和资源映射，不新增公共 API 或存档字段。角色保持现有五母体、少年、高阶与异常形态，脚底阴影及显示尺寸统一处理。动效为短淡入、轻呼吸和反馈；减少动态效果时禁用动画及位移。

## 验证记录

- 42 项现有规则测试：通过，覆盖新旧战斗模型、随机序列、实验、迁移与存档事务。
- 浏览器专项：16 项全部通过，覆盖 3 档桌面首页、3 档部署、物种档案、手机五页面、手机菜单键盘、实验取消/保存/三类结果、设置保存、回合奖励去重、失焦暂停与返回续局。最终结果见 `.verification/variant/browser-results.json`。
- 生产构建通过；Phaser 战场模块仍按需加载，保留其约 1.2 MB 未压缩体积提示。
- 20 组页面尺寸检查：1280×720、1366×768、1440×900、390×844 下的首页、档案、组池、实验室及人员页，无横向溢出；首页在三档桌面尺寸无纵向滚动。
- 1280×720 棋盘约 515×386px，三档桌面均通过宽度 ≥500、高度 ≥375 的断言，完整格子、备战席与五格商店可见。
- 100 单位、200 投射物，Chrome 153.0.8010.12 无头模式，同设备 360 帧：平均 59.34 FPS，P95 16.8ms，最高活跃音效 4；暂停后音效、音乐活跃数均为 0。音效上限 12 由现有规则测试覆盖。
- Safari 26.6（21624.4.5.11.5）已检测。WebDriver 明确拒绝创建会话：Safari 未启用 Allow remote automation。本轮未修改浏览器设置，Safari 功能验收未执行。
- 不支持模糊时仍由高不透明度面板提供背景。未进行独立旧浏览器引擎兼容测试。
