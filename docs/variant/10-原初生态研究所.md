# 首页视觉升级：原初生态研究所

实现日期：2026-09-06。以已确认的首页效果图为构图依据，保留明亮温室与克制神性，增加培养装置刻度和青色指示线。本轮只调整首页表现；其他页面的角色素材、战斗模型、经济、物种身份与存档字段保持原样。

## 操作与布局

- 桌面首页导航宽 248px。开始／继续出征为唯一最高强调入口；状态取自活动出征，不显示虚构资源。
- 主标题一组；谱系切换同步更换标题和母体。五个谱系按钮支持 Tab 和 Enter，切换后焦点留在原按钮，不改变存档或随机序列。
- 成长谱系、最近研究、区域调查合成一条底栏，桌面比例为 55 / 25 / 20。未知后代只显示剪影、编号和锁定标志；研究记录区区分首次发现、重复结果和失败。
- 390px 窄屏保留菜单抽屉，培养台下面提供独立的开始／继续出征按钮，底栏改为纵向排列。
- 返回中枢和续局沿用原有暂停逻辑；设置、Esc、焦点循环与焦点恢复行为保留。减少动态效果时不播放呼吸动画。

## 分层与素材

`src/variant/ui/home.css` 统一管理首页样式，旧的首页规则和末尾覆盖层已从公共样式中整理移除。`home-art.ts` 保存每种母体的路径、比例、脚底锚点和标题，均为展示配置。

场景分为温室远景、独立培养台、固定接触阴影、透明母体、SVG 前景刻度及光效。母体与台面使用同一个 4:3 坐标容器，呼吸动画只缩放身体且以脚底为原点；阴影和台面不随身体动画移动。

## 素材生成方式与提示词

使用内置 imagegen，未使用外部 API 或远程素材。透明底须经过实际 Alpha 检查，绘制了棋盘格的失败版本不接入工程。

REMOVE ALL TEXT, UI, letters, borders, menus, icons, status, creature, bottom information panels AND the central foreground circular pedestal. Keep bright warm ivory dawn from upper right, deep forest green shade on left third, luminous cyan faint biological conduits, quiet reflections. Right half luminous yet not overexposed. Foreground clear, middle distant architecture. No letters numbers plants-as-characters or animals, no foreground platform, no UI. Match approved image color and perspective.

母体共同提示词：

> Transparent background. Single isolated full-body game character PNG, true alpha background, no checkerboard. [species description] 90 percent serene primordial divinity and 10 percent understated friendly appeal. Beautiful realistic stylized dimensional render with organic jade and ivory tissue, soft warm daylight from upper right, faint cyan rimlight left. Feet firmly in a standing pose. No background, no floor, no ground shadow, no props, no pedestal, no border, no text. Transparent cutout asset for compositing into a premium biotech greenhouse game.

物种描述：原豆为双叶玉质种核、小眼睛与叶足；原花为三片象牙莲瓣包裹玉质种核；原根为树皮帽、单叶橡实与根足；原孢为玉质钟形菌盖、窄菌柄和根足；原节肢为玉质鞘翅、双触角及四条节肢。

花系、菌类和节肢进一步修订：缩小眼睛、去除额头珠宝和装饰性眼纹；菌类移除拟人手臂，改为单一菌柄；节肢移除金色装甲花纹，保留普通甲虫体态。最终抠图提示词为 “Remove the background. Keep the character unchanged. Transparent background PNG.”

培养台使用参考图独立提取重制：3:2 透明画布，低矮圆形玉质玻璃台面、细青色光带、象牙边缘、少量金属接缝，保留完整边缘，无场景、人物或文字。随后单独移除背景，保留真实透明通道。
