# 让生命成为研究所的主角

本轮精修首页、变种档案、遗传实验室及实验弹窗。采用明亮温室、象牙白、生物青与深绿玻璃材质，保留原有 45 物种、战斗规则、资源与 v4 存档。

## 已交付的体验

- 首页保留 248px 左栏，放大母体、缩小培养台；新增能力研究标签与可点击成长节点。五条谱系手动切换，未知后代显示编号和剪影。
- 点击成长节点进入相应谱系和物种详情。图鉴高亮当前节点、直接父代、后代及连线；筛选不再留下指向隐藏节点的悬空连线。
- 图鉴的“定位当前物种”会居中并聚焦节点。缩放后保留当前物种；父代、后代可点击，跨谱系时切换至目标体系；列表视图继续可用。
- 实验室分为条件、培养台、风险与投入三栏。材料槽与费用明细显示需要、持有及缺口；成功和失败比例合计 100%，异常率明确包含在成功率中。
- 确认实验之前不会抽样或扣费。结果先完成既有事务保存，再显示首次发现、重复发现或失败；实际投入及返还同时列出，最近实验记录可查。
- 手机按操作顺序纵向排列；弹窗内部滚动，底部操作始终可达。保留菜单焦点循环、Esc 关闭、关闭后焦点恢复、减少动态效果与本地续局。

## 结构与兼容

- 图鉴和实验室分别由 `src/variant/ui/archive.ts`、`laboratory.ts` 管理页面模板，`views.ts` 继续负责组合已有页面入口。
- `research-art.ts` 使用既有五种母体展示配置，并提供 node / card / detail 三种规格。默认原始图集渲染保留在 `organism-art.ts`；展示页面显式使用新版母体，部署、商店及战斗保持原素材。
- `research.css` 集中页面材质、文字和组件状态；从全局样式清理了旧图鉴、实验室规则。首页仍由 `home.css` 管理。
- 界面选择仅保存在内存中，没有新增存档字段、模型规则或公共 API。图鉴浏览及预览不会推进随机序列。

## 操作说明

1. 首页选择豆科、花系、根系、菌界或节肢类，再点击成长节点查看对应物种。
2. 图鉴可筛选体系，切换网络／列表；拖动查看网络，Tab 和 Enter 选择物种，“定位当前物种”找回当前节点。
3. 在详情里点击父代、后代继续探索；更多后代可展开。未知物种只公开编号、剪影和亲缘线索。
4. 实验室选择单体突变或杂交，以及具体母体与试剂方案。阅读候选概率和费用明细，再进入确认弹窗。
5. 取消或 Esc 关闭不会扣费；余额不足时按钮禁用。重复发现按照现有规则返还每项投入的一半，向下取整。
