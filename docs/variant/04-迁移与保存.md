# 迁移与保存

新版主存档键为 `variant-zero-v4`。局外研究、活动出征、设置、教学和成绩统一保存。准备阶段操作成功即写入；实验通过候选副本计算，只有写入成功才替换内存状态，写入失败不会扣试剂或推进实验随机序列。

实验、商店、战斗与奖励随机序列独立。预览不调用抽样；战斗使用本回合开战前阵容与固定种子，刷新回到准备阶段。结算使用出征内回合标记去重，奖励与研究记录同次提交。

迁移兼容旧加载器支持的 v1—v3，保留声音、减少动态效果、旧成绩纪念。三类旧母体对应原豆、原花、原根；旧九种后代按 solar→V-030、harvest→V-031、capacitor→V-032、bunker→V-033、volley→V-034、sentinel→V-035、generator→V-036、nurse→V-037、vault→V-038 解锁。新母体五种均初始开放。新手礼包五类Ⅰ级试剂各四份，迁移或新建时仅发放一次。

有效存档写入前保留上一个版本备份。检测损坏后不静默覆盖原始内容；界面提示使用可恢复备份。恢复时另存损坏原文。研究中枢支持导出 JSON；本版未提供跨设备同步或文件导入界面。

旧版完整源码归档：`backups/mutabloom-v03-before-variant.tar.gz`。恢复旧代码前另行备份当前工程；不要覆盖新版存档。源码中旧主入口保留用于回归测试，新版首页没有经典模式入口。
