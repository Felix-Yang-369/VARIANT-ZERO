# 世界观与标本图鉴更新

2026-09-06。沿用《异芽 MUTABLOOM：杂交花园》，从参考文本采用翠绿网络、枯潮、最后温室与植物实验室的设定，落地到现有三母体和三场出征。

## 世界设定

翠绿网络曾通过根系、菌丝与光交换生长的记忆。网络衰败后，植物失去自然进化的方向；枯潮让生命仍在生长，却逐渐失去秩序。

玩家继承最后一座仍有生命反应的温室，以及前任园丁未完成的遗传笔记。三类母体是花系、荚系、根系。杂交连接生长记忆，进化选择方向，突变承担已知风险。出征带回新的发现，逐步理解枯潮；其根源作为尚未解开的悬念。

清晨庭院是温室门前的第一道防线，午后追逐沿着外庭的根脉信号前进，花园实验室保存更深的遗传记录。现有四类敌人都是枯潮影响下失序的生态生命，并拥有各自的观察记录。

世界观入口：主页左下“最后温室，仍在发光”，或花园基地底部“阅读花园纪事”。实验室增加前任园丁的实验笔记，开战准备界面增加对应场景的叙事。

设定集中于 `src/lore.ts`，可以继续扩展。没有把参考文本里的新品牌、五大家族、新资源、Boss 和新地形当作本次玩法需求。

## 图鉴

12 张可展开的植物标本卡，包含档案编号、收录状态、家族、架空英文标本名、定位、真实基础属性、植物故事和记录地点。未发现的后代明确标为待培育预览，属性与当前内容定义一致。

卡面使用温室背景、透明渐层、磨砂玻璃框、内边缘高光、标本圆环和层叠阴影；角色保持清晰。标本记录使用原生 details / summary，可鼠标或键盘展开。窄屏自动调整列数；减少动态效果时关闭卡片抬升。

磨砂滤镜只应用于非战斗图鉴，包含 WebKit 前缀与无滤镜回退。
