# v0.3 素材与生成记录

模式：内置 imagegen 工具，未使用 CLI 或外部素材下载。20 张最终素材全部保存到 `public/art/` 并接入页面和 Phaser；生成原文件保留。场景为 1672×941 RGB，16 张角色为 1254×1254 RGBA，透明通道保留。棋盘在加载时将角色渲染到复用的 256×256 纹理，减少显存和小尺寸锯齿，原始 PNG 不修改。

主页采用温室场景独立加载；进入出征加载战斗素材。实际界面标题、概率、数字和按钮均由 HTML 绘制，没有烘焙在场景中。基因、进化、突变使用独立的叶芽标记、冠点、光环和色彩层。
