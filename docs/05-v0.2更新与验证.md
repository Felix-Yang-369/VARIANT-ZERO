# v0.2 更新与验证

日期：2026-09-05

## 完成内容

按“经典塔防的热闹感、电脑优先”实现。保留三关、单位与经济数值，新增事件驱动的视听反馈，重整操作和界面。

| 模块 | 交付 |
| --- | --- |
| 声音 | 17 种程序合成音效；轻快循环音乐，最终波次增加节奏与和声；没有外部素材或配音 |
| 音频生命周期 | 首次开始解锁；暂停停止当前声音并冻结音乐位置；新局清空声音与调度；高频音效合并，最多 12 个音效声部，重要提示可替换低优先级声部 |
| 设置 | 音乐默认 25%、音效 60%；静音、减少动态效果、教学状态本地保存；兼容 v1 解锁和静音偏好 |
| 画面 | 紧凑战斗布局、等比棋盘、立体卡片、放置预览、后坐与啃咬、受击与死亡、粒子、防线车尾迹、收集飞行、波次及路线提示 |
| 交互 | 模式优先，阳光不挡工具点击；属性对比；材料高亮、结果格与继承耐久预览；余额不足禁用；失效材料撤销 |
| 流程 | 重开与切关暂停确认，取消恢复原状态；弹窗焦点管理；第一关逐步教学，后两关能力引导，可跳过与重看 |
| 结构 | BattleEvent/drainEvents 一次消费；音频、交互、存档与场景分离；HUD 内容变化时才更新 |

音乐与视觉表现独立于战斗判定。阳光在成功点击时到账；融合预览期间继续战斗，确认时由原有模型再次验证材料与余额。胜负奖励和音效随一次性结算事件触发，不依赖弹窗渲染次数。

## 环境与验证覆盖

- macOS 26.6，Apple Silicon arm64；Node.js 22.22.2。
- Chrome 153：通过 Playwright 使用本机 Google Chrome 执行自动化，非替代内核。
- Safari 26.6（21624.4.5.11.5）：通过原生应用 UI 检查页面、角色、开局、种植（175 → 125）、暂停、设置弹窗、键盘音量调节与减少动态效果保存。
- Safari WebDriver 未开启远程自动化，因此没有把 Chrome 的自动化覆盖和性能数字视为 Safari 的结果；Safari 未执行三分辨率自动化矩阵或性能压力测试。

## 检查记录

单元与模型验证覆盖原有三关合法资源通关、一次性事件与结算、失效融合、输入模式、旧存档迁移、坏存档回退、音频并发优先级，以及暂停/重开的声部与音乐位置清理。

Chrome 浏览器验证覆盖 1280×720、1366×768、1440×900 的棋盘比例、完整显示和实际种植坐标；另检查预览、余额不足、阳光重叠、杂交继承耐久、失效材料、进化、设置持久化、弹窗焦点、取消恢复、重开清理、结算不重复，以及隐藏页面后主动继续。

检查时修复了两项问题：弹窗曾因背景 inert 范围过大而无法点击，现只屏蔽背景的 header/main；实时背景模糊增加暂停场景开销，改为半透明遮罩。

最终结果：**19 项规则/单元测试通过，11 项 Chrome 浏览器测试通过，生产构建通过。** 生产 JS 约 1.25 MB，gzip 约 339 KB；已确认生产包不包含开发检查接口 `__gardenQA`。

## 本机性能结果

1366×768，Chrome 153.0.0.0，同机测试。固定绘制场景暂停模拟，保留 100 个敌人与 200 发子弹，采样 240 帧；动态场景采样 360 帧并保持至少 200 发子弹。

| 场景 | v0.1 | v0.2 |
| --- | ---: | ---: |
| 普通运行场景 | 60.0 FPS | 60.0 FPS |
| 固定 100 敌人 / 200 子弹绘制 | 59.3 FPS | 60.0 FPS |

动态压力场景：100 个敌人、至少 200 发子弹、25 株速射植物、音乐和音效同时运行，平均 **60.0 FPS**，P95 帧间隔 16.7 ms。采样期间音效峰值并发 3，音乐峰值并发 2。音频 reset 后声部数为 0、音乐步进为 -1。17 种音效均生成非静音缓冲，未发现页面运行错误。

这些是本机短时采样，不是所有设备或长时间运行的帧率保证。执行 `npm run benchmark` 可复测动态场景，原始 JSON 位于 `.verification/`。

## 限制

手机仅基本适配；没有手机专项测试。Safari 为原生冒烟检查，未做完整自动化或性能验收。音效合成与非静音缓冲数据经过验证，没有进行专业设备上的听音和响度校准。生产引擎包仍较大，构建会显示单包体积提示。
