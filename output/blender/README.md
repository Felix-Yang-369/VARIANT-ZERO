# 零号变种 · 原初生态研究所三维场景

将用户提供的三张概念图重建到同一个 Blender 场景：温室大厅、薄玻璃培养台、V-001 原豆母体。采用项目当前“原初生态研究所”的象牙白、玉绿、生物青设计语言，并参考“翠绿网络”的根系与藤蔓意象。

正式场景名称为 **原初生态研究所 / PRIMORDIAL CONSERVATORY**，对应首页的研究中枢；角色名称为 **V-001 原豆母体**，谱系为 **豆科（legume）**，成长阶段为 **原初母体**。依据当前 `src/variant/ui/home.ts` 和 `src/variant/content.ts`，不采用旧版 `src/lore.ts` 的 Podwarden 作为当前正式英文名。详细映射记录在 `asset-names.json`。

2026-09-12 已同步重命名主文件、预览、场景、角色集合、角色对象前缀与相机。几何、材质和构图保持原样。旧名 `.blend1` 与 `.log` 是历史备份和运行记录。

## 文件

- `原初生态研究所_V-001_原豆母体_v1.blend`：可编辑的完整场景，用 Blender 5.2 创建。
- `原初生态研究所_全景_v1.png`：完整场景的实际 Blender 渲染。
- `V-001_原豆母体_培养台近景_v1.png`：原豆与培养台的实际 Blender 近景渲染。
- `build_sanctuary.py`：可复现的建模与材质脚本。
- `refine_scene.py`：建模脚本自动调用的叶片细化、材质与相机调整。
- `scene-manifest.json`：生成后的对象和打包参考图记录。

## 打开与编辑

打开 `.blend` 后按小键盘 0 进入相机，Home 可框选场景，选中对象后小键盘小数点可聚焦。右侧 Outliner 按建筑、椭圆装置、植物、培养台、原豆、灯光相机分组；它们位于同一个 Scene，保留独立对象便于后续精修。

相机 `CAM 01` 为大厅全景，`CAM 02` 为原豆与展台近景，`CAM 03` 为角色正面。选中相机后 Ctrl + 小键盘 0 可设为活动相机。按 F12 渲染。

三张原图均已打包进文件，在隐藏的 `07` 参考集合中；渲染中的建筑、植物、培养台与原豆均为实际几何，不依赖图片平面充当模型。材质为程序材质，文件不依赖外部纹理路径。植物叶片共享网格以减少重复数据。

## 本版范围

这是依据单视角概念图制作的首版三维重建；背面与空间布局为补充设计，不是扫描或逐像素复刻。原豆为未绑定的静态模型；尚未制作动画骨骼、游戏低模、烘焙贴图或碰撞体。没有改动网页与游戏逻辑。
