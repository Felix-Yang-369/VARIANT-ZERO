## 摆位和更新

在 Outliner 的 `01 • 链接资产` 集合下选中实例，用 G、R、S 调整整个资产的位置、旋转、比例。这些实例控制属于总场景本地数据，普通摆位不需要库覆盖。角色顺序为左侧苔行者、中间原豆母体、右侧疾藤潜行者。

修改并保存角色或研究所原文件后，重新打开总场景即可读取更新；也可以在 Outliner 的 Blender File 视图下找到对应 Library，执行 Reload。内部骨骼和对象的独立编辑需要 Library Override；本版没有骨骼动画。

灯光与相机统一保存在本地 `02` 集合。没有链接敌方角色源文件中的影棚地面、背景、灯光或参考板。

## 文件依赖

链接使用相对路径。请保留整个 `output/blender` 的相对目录结构，或者整体移动它；总场景不能脱离三个源文件单独使用。若移动源文件，需要在 Blender 中重新定位 Library 路径。

`linked-assets.json` 记录引用关系，`verification.json` 是重新打开后的检查记录，PNG 为实际 Cycles / RTX 5060 OptiX 渲染。上一级 `build_linked_scene.py` 可重建总场景，`prepare_environment_link.py` 可给已有研究所源文件准备环境集合。
