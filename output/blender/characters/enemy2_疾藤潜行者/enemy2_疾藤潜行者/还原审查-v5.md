# 疾藤潜行者 v5 · 连续根结与表面形态

本轮继续以 `public/art/enemy2.png` 为主参考，保留 v4 的多角度姿态，针对实际渲染中的造型差距修改。v4 独立文件和总场景链接保留。

## 本轮修改

- 将掌部与三根手爪、足掌与三根足爪分别合并并进行体素重建，消除原来的球形掌部与根爪之间明显的相交接缝。生成四块连续融合根结，保留分离尖爪轮廓。
- 融合表面添加平滑过渡与不规则起伏；纵向木纹曲线通过 Shrinkwrap 贴合实际融合网格。重建部分使用独立程序化材质，避免失去 UV 后出现空白贴图。
- 面甲分片沿不同的弯曲路径展开，打破 v4 的近似竖直木板分缝。试渲染中额外的细裂曲线显得悬浮，已去掉，最终以真实木片边界表现裂缝。
- 紫叶新增低频褶皱和边部波动，降低部分直立叶尖并向后推移，调整深紫色阶与粗糙度。
- 晶核内加入一条主脉和稀疏侧分叉；减细眼窝边缘，降低大片灯光反射，保留尖叶形渐变发光核心。

## 验证与边界

使用固定中性灯光检查八向视图及面部、根爪、叶冠近景，最后以暖色主光和紫色背光输出主图。验证脚本重新打开保存的资产，再从独立场景 Link 根集合、保存并重开测试场景。渲染使用 RTX 5060 / OptiX。

额外执行 `check_stalker_v5_fusion.py`：四块手足融合网格分别只有一个连通体，非流形边数均为 0。记录为 `fusion-verification-v5.json`。此项只验证四块融合网格，不代表整个角色已完成游戏拓扑优化。

这是进一步修订的高细节静态资产，未做骨骼、动画和游戏 LOD。原图的树皮破损、木根分叉及材质层次仍有更复杂的细节，不声称完全复制原图。尤其不能将面数或渲染采样数作为相似度证据。
