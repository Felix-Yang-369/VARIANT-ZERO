# 零号变种 · v2 精修版

基于现有三个角色和研究所源文件细化，单独保存 v2；v1 模型与总场景均保留。总场景使用四个真正的 Link 集合实例引用三个 v2 源文件，集合名称保持稳定。

## 本轮修改

- 苔行者：增加有面部开口与厚度的立体破叶兜帽；树皮由连续表面增加不规则叠片；苔藓改为扁平绒毯基底和细小分枝叶；补充毛细叶脉和表面微纹理；紫眼增加边缘明暗变化，移除白色贴片式高光。
- 疾藤潜行者：增加叠层树皮与浅表起伏、额侧卷曲木须、细叶苔藓、紫叶毛细脉及晶质眼睛。
- 原豆母体：玉叶增加低对比细胞纹理、真实毛细叶脉几何和微小表面起伏，调整叶肉与种核材质。
- 研究所：增加立柱分段箍与检修面板细节、林下羽状蕨叶，以及可反射折射的屋顶玻璃和材料微纹理。

源文件：

- `原初生态研究所_V-001_原豆母体_v2.blend`
- `characters/enemy0_苔行者/苔行者_enemy0_v2.blend`
- `characters/enemy2_疾藤潜行者/疾藤潜行者_enemy2_v2.blend`

总场景：`scenes/原初生态研究所_三角色展示/原初生态研究所_三角色_Link总场景_v2.blend`。

总场景预览为 2400×1600、Cycles 128 samples；角色精修预览为 1300×1500、96 samples。渲染脚本明确启用 RTX 5060 / OptiX。

`refine_assets_v2.py` 以打开的 v1 源文件为输入生成 v2，`scenes/build_linked_scene_v2.py` 重建对应总场景。重新运行会覆盖同名 v2 输出。检查记录保存在各文件夹的 `verification-v2.json`，几何统计在 `refinement-v2.json`。

本版仍是风格化静态精修，并非原概念图全部微观细节的逐像素复刻；没有增加骨骼动画、烘焙贴图或游戏低模。角色改动需要在对应 v2 源文件中保存，再重新加载 v2 总场景。
